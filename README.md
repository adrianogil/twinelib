# twinelib

Python library to parse and generate Twine stories.

## Samples

This repository includes sample assets in the `samples/` directory:

- `samples/dragon.json` is a more complete, multi-path example story.
- `samples/test.py` loads the sample JSON and renders it to `dragon_story.html`.

To try the sample script from the repository root:

```bash
python samples/test.py
```

Then open `dragon_story.html` in a browser to view the rendered story.
